PRODUCT DEMO

One scan: profile in, prioritized briefing out

1 · Profile

Name, aliases, description, website, region, industry, monitoring priorities.

2 · Scan

Visible stage-by-stage progress. Live web or a clearly labeled fixture set.

3 · Feed

Review now → Watch → Digest → Ignore, with category, report type and flags such as “allegation, not fact”.

4 · Evidence

A source passage checked word for word against the stored text, plus Drex’s probabilities, labeled as model estimates.

Demo cases

Namesake nursery and musician → ignored
Funding repost → repeat, digest
Pricey review → digest
Scam accounts, data exposure, regulator inquiry → review now

Demo flow: load the fictional Nimbleroot profile, run the fixture scan, open the staging-bucket article to show the verified passage and Drex’s probabilities, show the briefing, then switch to Live and scan a real company.
