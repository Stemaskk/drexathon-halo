ARCHITECTURE

Each tool does one job

KEENABLE

Retrieve

Identity-aware, date-filtered search; fetch article text. Deduplicated by canonical URL.

NDI

Extract

Markdown upload → JSON schema: entities, claims with status (alleged, stated…), dates, verbatim passages.

DREX

Decide

6 typed questions in one call: right subject? category? report type? new? action? urgency? Probabilities kept.

OUR RULES

Guard

Namesake cutoff, uncertain identity → watch, repeat coverage downgraded, verbatim evidence check.

DEEPINFRA

Explain

Qwen3.8-27B writes the briefing from Drex’s decisions and verified evidence only.

React + FastAPI, Vercel-ready. Keys stay server-side. API failures are shown, never swapped for mock data. Intern (Drex + Qwen) was used as a coding agent to write and run the pipeline’s unit tests.

The split matters: Drex makes the typed judgments, and the LLM only writes prose about decisions that were already made. That keeps the expensive, slow model out of the per-article loop.
