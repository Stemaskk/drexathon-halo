LIMITATIONS & NEXT STEPS

What this does and doesn’t show

Limits

The offline demo set is 18 synthetic articles about a fictional company.

Advice is written by an LLM from the evidence, so it needs a human read before acting on it.

No live stock-price or ad-platform data: only public coverage of them.

NDI is the slowest stage (~7–14 s per article).

Next

Run a cheap Drex identity check before NDI so namesakes never get extracted.

Scheduled scans with email and Slack alerts.

Measure Drex against a frontier LLM on speed, cost and accuracy.

Profile and policy documents uploaded through NDI.

The architecture point: typed decisions go to a small decision model, and the LLM only writes prose from those decisions and verified evidence.
